# VinWave DSP Studio

VinWave DSP Studio is a professional Digital Signal Processing Engineering Workspace designed for speech enhancement using classical DSP algorithms.

The application is designed as a desktop-first engineering environment for analyzing, enhancing, comparing, and exporting speech signals.

## Features

- Audio import
- Audio recording
- Waveform visualization
- FFT visualization
- Spectrogram visualization
- Signal analysis
- Spectral Subtraction
- Wiener Filter
- Voice Activity Detection
- Audio comparison
- SNR analysis
- Processing history
- Audio export
- Interactive signal inspection
- Professional dark engineering interface

## DSP Algorithms

### Spectral Subtraction

Classical noise-reduction technique for reducing stationary background noise.

### Wiener Filter

Frequency-domain filtering technique that estimates the clean speech signal based on signal and noise characteristics.

### Voice Activity Detection

Detects speech and non-speech regions in an audio signal.

### MMSE Estimator

Planned for a future version.
